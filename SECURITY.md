# Security Policy

## Reporting a Vulnerability

To report a security vulnerability, please refrain from creating a public issue on GitHub.

Instead, contact the QIM Developer Team via [`support@qim.dk`](mailto:support@qim.dk) with details about the vulnerability you have found.

Thank you for engaging in responsible disclosure.
You will get back to you as soon as possible — you should expect a reply within a couple of business days.
