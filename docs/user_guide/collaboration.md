# Collaboration

Contributions to `qim3d` are welcome!

If you find a bug, have a feature request, or would like to contribute code, please open an issue or submit a pull request.

You can find us at GitHub:
[https://github.com/qim-center/qim3d](https://github.com/qim-center/qim3d)

Otherwise, feel free to reach out at [info@qim.dk](mailto:info@qim.dk)
