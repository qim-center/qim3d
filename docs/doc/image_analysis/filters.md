# Filtering data

The `qim3d` library provides a set of methods for filtering volumes.

::: qim3d.filters
    options:
        filters: ["!^_"]
        members:
            - gaussian
            - median
            - sobel
            - maximum
            - minimum
            - tophat
            - Pipeline
